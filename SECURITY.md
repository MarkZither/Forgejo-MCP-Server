# Security Policy

## Reporting a Vulnerability

We take the security of Forgejo-MCP-Server seriously. If you have discovered a security vulnerability, please report it responsibly.

**Where to report:**
link to security.zither-it.co.uk

**What to expect:**
- We aim to respond to security reports within **1 week**
- We will work with you to understand and validate the issue
- We will keep you informed of our progress toward a fix
- We will credit you for the discovery (unless you prefer to remain anonymous)

**What to include in your report:**
- A clear description of the vulnerability
- Steps to reproduce the issue
- Potential impact of the vulnerability
- Any suggested fixes or mitigations (optional)

**Please do not:**
- Publicly disclose the vulnerability before we have had a chance to address it
- Exploit the vulnerability beyond what is necessary to demonstrate it

Thank you for helping keep Forgejo-MCP-Server and its users safe.
